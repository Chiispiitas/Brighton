3. Part 5 overlays

Import separate transparent files for each colour. Required palette: red, blue, green, brown, purple, yellow, orange and pink. Optional base files can be used before the student chooses a colour. The example hat only needs yellow.

Recommended names: q21_jacket_red.png, q22_backpack_blue.png, q23_bicycle_green.png, q25_umbrella_purple.png, etc. Use _base for an uncoloured version and example_hat_yellow.png for the example.
