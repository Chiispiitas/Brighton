BRIGHTON A1 LISTENING FINAL - ELEVENLABS V3 SCRIPT PACK

Format
------
25 questions, 5 parts, 5 questions per part.

Part 1: People in a scene - matching
Part 2: Note completion
Part 3: Family activities - matching
Part 4: Picture multiple choice
Part 5: Picture colours and writing

Recommended audio workflow
--------------------------
1. Generate each part separately in ElevenLabs V3 using the corresponding TXT file.
2. Keep the expressive tags such as [happy], [curious], [thoughtful], [short pause], [pause], and [long pause].
3. Use clearly different voices for the alternating speakers.
4. Do not speed up the audio. A1 students need natural but clear pacing.
5. Each scored section is already repeated once in the script.
6. When all five tracks are approved, combine them in this order into one file named audio.mp3 for the Brighton exam player.
