# Horizons examples

`stage-2-showcase.html` demonstrates the current native HTML5/CSS production system.

It contains four A4 examples:

1. Lesson-opening page for 3A
2. Second-page grammar/listening/practice layout for 3A
3. Real-world review/interface layout for 3C
4. Unit Review layout

## What the showcase now proves

Every numbered exercise flows in one vertical column. Visual density comes from internal layouts inside each exercise:

- photo + reading feature panels;
- two- and three-column question grids;
- compact skill/mode bars;
- timelines;
- vocabulary chips;
- grammar focus surfaces;
- audio + QR panels;
- review cards;
- self-check modules.

The design uses an original Horizons identity: indigo/aqua/coral/sun/plum accents, asymmetric rounded geometry, multicolor horizon rails, offset lesson stamps and a vertical exercise spine.

The screenshots used as design references informed only broad editorial principles such as hierarchy, skill labeling, varied media scale and compact exercise rhythm. Their exact page composition, colors, tabs, icons, typography and decorative structure are not reproduced.

These examples are **layout demonstrations only**. They do not replace, rewrite or modify pre-existing Student's Book pages and do not change the locked syllabus.
