# Horizons examples

`stage-2-showcase.html` demonstrates the current editorial HTML5/CSS production system.

It contains four A4 examples:

1. Lesson-opening page for 3A
2. Second-page grammar/listening/practice layout for 3A
3. Real-world review/interface layout for 3C
4. Unit Review layout

## What the showcase proves

Every numbered exercise flows in one vertical sequence. Visual variety comes from layouts **inside** each exercise rather than by placing exercises beside one another.

The current examples emphasize:

- one dominant unit color;
- neutral typography;
- large raster-photo areas;
- simple exercise numerals;
- thin editorial rules;
- substantial white space;
- flat grammar/reference areas;
- two- and three-column internal question grids;
- rounded/shadowed styling only where a simulated real-world interface benefits from it;
- bespoke CSS for individual page features instead of turning every visual idea into a reusable card component.

The screenshots used as references informed only broad editorial principles such as hierarchy, skill signaling, varied media scale and activity rhythm. Their exact composition, colors, tabs, icons, typography and decorative structure are not reproduced.

These examples are **layout demonstrations only**. They do not replace, rewrite or modify pre-existing Student's Book pages and do not change the locked syllabus.
