# Horizons Student's Book production

This directory is reserved for final production lesson HTML once layout demonstrations are approved.

Recommended structure:

```text
student-book/
├── unit-01/
│   ├── 1a.html
│   ├── 1b.html
│   ├── 1c.html
│   ├── 1d.html
│   └── review.html
├── unit-02/
│   └── ...
├── vocabulary-practice/
└── grammar-reference/
```

## Production rule

Do not copy example/showcase HTML wholesale into this directory. Each production lesson should:

1. start from the locked structured syllabus entry;
2. have a validated content record;
3. choose a spread archetype/density deliberately;
4. use final or intentionally tracked placeholder assets;
5. keep numbered exercises in one vertical lane per page;
6. pass browser and print QA before approval.

The pre-existing `Horizons A1/` Student's Book remains frozen and separate.
