# Horizons examples

The examples directory is a visual laboratory for the native HTML5/CSS production system. All copy is demonstration material only; examples do not replace or rewrite frozen Student's Book pages.

## Stage 2 — media / overlays

`stage-2-showcase.html`

Demonstrates:

- full-photo lead with title/text overlay;
- offset copy overlapping a photograph;
- photo collage with inset detail crops;
- pull quote crossing an image edge;
- lower-third photo information band;
- numbered/lettered image strips;
- internal question grids.

## Stage 4 — publication system

`stage-4-publication-showcase.html`

Demonstrates the system working as a real publication rather than isolated components:

1. a **two-page reading-led lesson spread** with strong contrast between opener and continuation;
2. long-form editorial typography, pull quote and stable exercise IDs;
3. differentiated **Grammar** and **Pronunciation** treatments;
4. functional SVG task icons;
5. page-ending communication/reflection patterns;
6. a spatial/tiny-home spread using a plan, feature reading and process strip;
7. density presets;
8. unit-specific feature motifs;
9. Vocabulary Practice back matter;
10. Grammar Reference back matter.

## Unit Review spread

`unit-review-spread-showcase.html`

Demonstrates the full two-page review architecture with:

- visible consolidation of Lessons A–D;
- denser vocabulary/grammar practice;
- integrated reading/listening slots;
- final communicative/writing challenge;
- readiness score;
- spread-level continuation treatment.

Unit Reviews intentionally prioritize consolidation and navigation over feature-page photography.

## Non-negotiable rule demonstrated by every stage

Every numbered exercise flows in one vertical sequence. Visual variety comes from layouts **inside** each exercise rather than by placing exercises beside one another.

## Reference-material boundary

External coursebook screenshots may inform broad editorial principles such as hierarchy, skill labeling, varied media scale, information density and activity rhythm. Their exact page compositions, colors, tabs, icons, typography and decorative structure are not reproduced.
