# Brighton Adaptive Placement — ElevenLabs Listening Scripts

Production file for Stage 03 Listening.

## Format

Listening is **not** one continuous recording.

Each question uses:
- one independent MP3 file;
- one independent audio player;
- a maximum of **3 complete plays**;
- playback at normal speed only;
- no seeking or scrubbing;
- no pause/resume during a play;
- the replay counter increases only after playback successfully starts;
- moving to another question stops the current clip.

Students are routed to **one** level-matched listening module. Each module contains **3 questions**, so a student hears only three clips.

Target time for the whole Listening stage: approximately **2–3 minutes**.

## ElevenLabs production direction

Use natural conversational English, not an exaggerated teaching voice.

Recommended baseline:
- neutral British / international English;
- natural pace for the target level;
- clear but not artificially over-enunciated;
- no music;
- no sound effects unless a script explicitly requires one;
- keep pauses natural and short;
- export MP3 at consistent loudness.

For dialogue clips, use two clearly different voices. Do not read speaker labels aloud.

File path planned for the app:

`Placement/audio/listening/<filename>.mp3`

**Voice:** female, analytical radio/podcast tone.

**ElevenLabs script**
