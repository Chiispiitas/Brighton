# Horizons — Stage 2 Examples

`stage-2-showcase.html` is a four-page print-layout demonstration for the new A4 shell.

It includes:

1. a right-hand lesson-opening page using the existing `3A — What’s your routine?` syllabus heading;
2. the facing left-hand lesson-practice page with grammar, listening, answer lines and QR reservation;
3. a real-world review/interface treatment using the existing `3C — Where do you go?` syllabus heading;
4. a Unit 3 Review layout example.

These pages are **layout demonstrations only**. They do not replace, revise or overwrite any Student's Book page and are not final editorial lesson content.

Image areas intentionally use `hz-media-placeholder`. Final production pages must replace them with approved free raster photography or generated raster assets.

## Preview

Open `stage-2-showcase.html` locally in Chromium/Chrome/Edge after cloning the repository.

For PDF output use:

- A4
- Portrait
- 100% scale
- No browser margins
- Background graphics enabled
- Browser headers/footers disabled

The showcase should produce four separate A4 pages.
