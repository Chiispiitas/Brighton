1Match the need to the useful question. Write a–d.

  1. You didn’t hear the time.
  2. You need the price.
  3. You need the departure time.
  4. You need the name letters.

a How much is it?

b Can you spell your name?

c Can you repeat that?

d What time does it leave?

2Read the booking. Correct the agent’s confirmation.

Customer’s choice: Bristol · Friday · return · 10:30 · $45

Agent: “That’s a one-way ticket to Bristol on Thursday at ten thirteen. Forty-five dollars.”

Three details are wrong. Write the correct confirmation.
