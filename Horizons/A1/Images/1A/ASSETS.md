# 1A image usage

The opening conversation uses the original full `Tom and Mary.png` photograph,
including its hallway background, at the author's request. The transparent
cutout is retained as a previous version and is not used in the lesson.

`Tom and Mary-cutout-v2.png` is a 1448 x 1086 RGBA photographic cutout generated
with the built-in image tool on 2026-10-06 from `Tom and Mary.png`. It retains the
two opening characters, greeting gesture, clothes and backpacks while removing
the hallway background. The source image is preserved beside this version.

The previous cutout integrated the people with the dialogue feature's warm paper surface.
It contains no instructional text. The PNG has genuine alpha transparency with
zero alpha at all four corners; production retains the tool-generated alpha.
The exact edit prompt is stored with the redesign deliverables outside Git.

Other approved 1A photographs retain their source pixels and task roles.
