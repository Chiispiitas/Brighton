# Listening MP3 assets

Upload the ElevenLabs clips from `../../LISTENING_AUDIO_SCRIPTS.md` into this folder.

The Placement app expects these exact filenames:

```text
prea1-01.mp3
prea1-02.mp3
prea1-03.mp3
a1-01.mp3
a1-02.mp3
a1-03.mp3
a2-01.mp3
a2-02.mp3
a2-03.mp3
b1-01.mp3
b1-02.mp3
b1-03.mp3
b1plus-01.mp3
b1plus-02.mp3
b1plus-03.mp3
b2-01.mp3
b2-02.mp3
b2-03.mp3
c1-01.mp3
c1-02.mp3
c1-03.mp3
```

Do not combine the clips. Every question has its own player and its own three-play allowance.
