# Horizons examples

`stage-2-showcase.html` demonstrates the independent native HTML5/CSS production system.

It contains four A4 layout examples:

1. Lesson-opening page for 3A
2. Second-page grammar/listening/practice layout for 3A
3. Real-world review/interface layout for 3C
4. Unit Review layout

These are **layout demonstrations only**. They do not replace, rewrite, or modify pre-existing Student's Book pages, and they do not change the locked syllabus.

The showcase intentionally avoids reproducing the legacy book's magenta/navy geometry. It uses the new cobalt/coral/mint palette, rounded web-native cards, system fonts, semantic HTML5 elements, CSS Grid/Flexbox, and raster-image placeholders.
