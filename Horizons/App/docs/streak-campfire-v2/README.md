## Reproduce a new animation

1. Reopen the actual motion reference at normal speed and inspect enough closely spaced frames to understand anticipation, acceleration, impact, overshoot and recovery. Describe those actions in a timed storyboard using the app's own visual identity.
2. Pin the accepted character identity, permanent faceless head and separate expressions. When no permanent blank head exists, generate it and reconstruct the accepted still before proceeding. Do not make expressions by swapping whole heads or painting over the face.
3. Design a part inventory and joint hierarchy for the complete requested arcs. Specify hidden overlap, proximal/distal pivots, grip points and held-object anchors before generation.
4. Author one whole component per native image, run `tools/check-image-brief.py`, and actually attach its returned mandatory references and targets to ImageGen. Keep native outputs and exact failure evidence. Reject clipped ends, missing hidden material, changed identity, halos, unsupported grips or unsuitable silhouettes.
5. Run `tools/prepare-streak-v2.py` to key/crop and register complete native pixels. Uniform placement is preferred when it matches the reference; disclosed whole-component independent-axis calibration may preserve measured shaft width and true cap-centre reach. Never truncate concealed ends or draw replacement anatomy. Inspect the whole-parts board and every extreme. Adjust anatomical registration or regenerate a part when necessary; do not compensate with a combined-picture warp or a drawn skin cover.
6. Implement the hierarchy and inspect its real SVG poses. Run `tools/capture-streak-v2-stills.mjs` to export the actual renderer at 0 and 7600 ms for startup and reduced/failure stills. The Pillow construction boards are planning evidence, not replacements for these exact renderer exports.
7. Freeze registered art and renderer sources, then verify normal speed, joint caps, both grips, actual head/burst bounds, mobile/desktop fit, pause/disposal, missing-part fallback and reduced motion. Check the offline cache against the exact final bytes.
8. Run `tools/prepare-streak-v2.py --provenance-only` after final source changes. This refreshes records and hashes without rewriting frozen art. Update the animation audit with the current references, accepted limits and superseded decisions.
